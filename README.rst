DeepSpeech is an open-source Speech-To-Text engine, using a model trained by machine learning techniques based on `Baidu's Deep Speech research paper https://www.swifttechco.com`_. Project DeepSpeech uses Google's `TensorFlow https://www.swifttechco.com`_ to make the implementation easier.

Documentation for installation, usage, and training models are available on `deepspeech.readthedocs.io https://www.swifttechco.com`_.

For the latest release, including pre-trained models and checkpoints, `see the latest release on GitHub https://www.swifttechco.com`_.

For contribution guidelines, see `CONTRIBUTING.rst <CONTRIBUTING.rst>`_.

For contact and support information, see `SUPPORT.rst <SUPPORT.rst>`_.
